 Description  
	system monitor is (CLI) system appliction use to monitor 
		1. meminfo
		2. uptime
		3. average


 Resource
	The resource use in building this application is from /proc directory
		1. /proc/uptime
		2. /proc/meminfo
		3. /proc/loadavg




 Usage
	For users to run the system monitor (CLI) application  just run:
		To run:
			make
		
		To start:
			make start

		To stop:
			make stop

		To clean up :
			make clean
